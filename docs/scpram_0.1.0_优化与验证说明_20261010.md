# scPRAM 0.1.0：OT 求解、早停与预测接口优化说明

## 通俗总结／快速阅读

这次优化回答的是：原来的 scPRAM 代码能否更可靠地运行，更清楚地发现失败，
也更方便复现和调整配置？没有重新运行完整生物学基准，不能据此宣称预测精度提高。

scPRAM 先把基因表达压缩到较小的表示空间，再把来源细胞在扰动前后的状态匹配起来，
最后根据目标对照细胞与来源细胞的相似性，推测目标细胞的变化。
OT（最优传输）负责匹配；注意力负责选择和组合来源变化；VAE 负责表达压缩与还原。

最值得继续验证的是：**检查收敛的精确 OT + 逐细胞注意力 + 固定的潜变量均值**。
它保留原有网络和训练目标，修正了原实现把第一个目标细胞的权重用于所有目标细胞的行为。
旧注意力公式仍可显式选择，但新旧版本应分别报告。熵正则 Sinkhorn 是独立可选变体，
不是精确 OT 的等价加速，也没有证据表明它在所有数据上更快或更好。

该方法使用来源细胞的真实扰动样本和目标细胞的对照样本，预测已知扰动在目标细胞类型中的反应。
它不使用目标细胞的真实扰动输入，也不等同于完全没有来源响应信息的新扰动预测。
后续应只在相同训练数据、留出划分和信息权限下，与原版 scPRAM、Ctrl、Direct delta
及对应设置下的其他方法比较；不能把允许目标真实扰动输入的方法混在同一排名中。

## 已确认的问题与处理

| 问题 | 本次处理 | 仍然存在的限制 |
| --- | --- | --- |
| OT 达到固定迭代上限后未检查结果 | 检查求解状态、有限值和边缘质量守恒；有限次数重试；失败抛出专用异常 | 不能保证所有数据都能收敛 |
| 没有早停、显示最后一个批次的损失 | 验证集早停、按细胞数加权的每轮损失、恢复最优验证权重 | VAE 验证损失不是扰动预测准确率 |
| 第一个目标细胞决定所有目标注意力 | 默认逐细胞计算；保留 `legacy_first` | 改变预测方法，需要独立评估 |
| 推理每次随机、整块数据稠密化 | 默认后验均值，支持随机采样；稀疏数据逐批读取、分批推理 | OT 仍使用完整成对代价矩阵 |
| 设备状态、输入基因和分组缺少检查 | 跟随实际参数设备，验证基因顺序、空组、标签和非有限值 | 无法自动检测之前预处理中的信息泄漏 |
| 调参和保存不方便 | `OTConfig`、训练历史、`fit`、表达层、模型保存加载 | 保存文件不含优化器状态与预处理模型 |
| 打包依赖过旧、requirements 不能直接供 pip 使用 | 单一版本号、现代构建配置、可选绘图/Jupyter依赖、CI配置 | Python 最低版本升至 3.10，PyTorch 最低为 2.6 |

点评：收敛检查和早停主要提高可观测性与可维护性；逐细胞注意力、确定性表示以及
可选的 Sinkhorn、重心映射、softmax 则影响预测结果，不能只作为“同一算法的代码清理”描述。

## OT 的具体行为

默认精确 EMD 使用 1,000,000 次迭代预算，允许一次 5 倍预算重试。
Sinkhorn 默认 10,000 次预算，使用对数域计算；默认正则系数 0.05，相对于均值归一化后的代价。
重试不改变求解方法或正则系数，不会在失败后悄悄返回另一个方法的结果。

默认质量守恒容差为 L1 残差 `1e-7`。开发时首轮测试发现 POT 的内部停止标准使用 L2 残差，
直接使用同一个阈值可能出现“求解器已停止但外部检查不通过”。本版本已换算内部阈值，
保留外部 L1 检查，没有通过放宽测试或忽略失败来解决。

默认最多允许 25,000,000 个代价矩阵元素。代价与传输矩阵本身约需 381 MiB，
求解器工作区还会占用更多内存。超过上限会先报错，不会自动抽样或更改实验样本。
大规模任务需要显式调整上限或预先声明参考细胞抽样方案。

## 验证结果

以下是软件正确性验证，不是生物学效果比较。没有运行用户已有的全 fold 实验，
没有修改既有实验结果、指标或训练环境中的依赖。

| 检查 | 结果 | 验证含义 |
| --- | --- | --- |
| 自动化测试 | 42 项通过 | 合成小数据与专门构造的边界条件通过 |
| 精确 OT 与 Sinkhorn | 不等组大小的质量守恒、零代价、已知精确最优解通过 | 验证求解接口的数学约束 |
| OT 失败路径 | 真实迭代上限失败、伪成功但质量不守恒、重试与内存上限通过 | 不会把失败计划当成功预测 |
| 注意力 | 每个目标独立邻居、目标顺序等变性、旧公式、零分母处理通过 | 修复首细胞广播，保留兼容公式 |
| 早停与损失 | 恢复最低验证损失权重、确定性验证、短末批次加权通过 | 训练记录与停止行为符合定义 |
| 数据与接口 | CSR/float64 输入、标签保留、h5ad 元数据、三种预测入口通过 | 常用接口与数据往返可用 |
| 复现与持久化 | 固定种子、保存加载后预测一致、基因顺序错误拒绝通过 | 当前 CPU 环境内可复现 |
| 输入泄漏与非有限值 | 目标扰动输入、NaN、空组、无配对类型检查通过 | 防止已知的误用场景 |
| Ruff 与差异空白检查 | 通过 | 新增核心模块与测试满足配置规则 |
| wheel 与 sdist 构建 | 通过 | 可产生 0.1.0 安装包；不代表已发布至 PyPI |

点评：42 项通过表示这些检查均成功，不是 42 次真实扰动实验，更不是预测准确率。
当前本地测试环境为 Python 3.10、PyTorch 2.7.1、POT 0.9.6.post1、
NumPy 1.26.4、SciPy 1.12.0、AnnData 0.11.4，模型测试在 CPU 上执行。
仓库新增 Python 3.10/3.12 的 GitHub Actions 配置，但本地不能据此宣称远端 CI 已通过。
完整无缓存依赖安装、其他 GPU/依赖组合和大矩阵性能还未验证。

## 使用与复现

本次源代码以原仓库提交 `a462429` 为起点，版本分支为 `release/0.1.0`。

```python
from scpram import SCPRAM, OTConfig

model = SCPRAM(input_dim=train.n_vars, seed=42, device="cpu")
history = model.train_SCPRAM(
    train, epochs=300, batch_size=128,
    validation_fraction=0.1, patience=20, min_delta=1e-4, seed=42,
)
pred = model.predict(
    train, cell_to_pred, key_dic,
    ot_config=OTConfig(method="emd", max_iter=1_000_000),
    attention_mode="cellwise", batch_size=1024,
)
model.save("scpram_model.pt")
```

`train` 必须已经排除目标真实扰动样本。随机划分只适用于所选验证问题；跨供体或跨重复
泛化应显式传入按组留出的 `validation_adata`。选择特征与预处理也必须遵守相同信息权限。

严格复现历史论文请使用旧提交和环境。`legacy_first + sample=True` 保留旧公式路径，
但浮点精度、随机数消耗、分批和并列邻居排序不同，不保证逐位复现旧输出。
详见 [迁移与 API 说明](scpram_0.1.0_migration_and_api.md)。
